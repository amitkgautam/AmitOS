# AmitOS — Setup Guide

## A. What each file is

### index.html
Main structure of the AmitOS application.

### style.css
All visual styling, responsive layout, cards, buttons, forms and themes.

### data.js
Default configuration, default habits, improvement categories, achievements and optional demo data.

### app.js
Main AmitOS application logic:
navigation, forms, calculations, localStorage, statistics, import/export and rendering.

### SETUP.md
This setup and troubleshooting guide.

---

# B. Creating the project

Create a folder named:

AmitOS

AmitOS/
